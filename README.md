# AM Chatbot for Health, Business & Investment

An AI-powered chatbot built using Dify and Gemini 2.5 Flash.

## About

AM Chatbot is a Generative AI chatbot designed to provide conversational assistance in:

- 🏥 Health
- 💼 Business
- 📈 Investment

## Technologies & Tools

- Dify
- Gemini 2.5 Flash
- Generative AI
- Large Language Model (LLM)
